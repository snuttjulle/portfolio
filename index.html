Custom Vulkan Game Engine

Personal Project · C++ / Vulkan · Treptow Art Studio
A custom C++ game engine built on the Vulkan rendering API, designed to emulate the technical restraints of the Nintendo 64 and PlayStation era of computer graphics but with a modern rendering approach.
▸ Click to expand
🎮 Key Art Placeholder
Overview

Started as a small Vulkan prototype to learn the rendering API and grew into a full custom game engine written in C++. Designed to emulate the technical restraints of the Nintendo 64 and PlayStation era: vertex imprecisions, limited color palettes, dithering, and down-sampled resolutions, but with a modern rendering approach. Having grown up playing N64 and PlayStation games, I wanted to recreate that era's distinctive look with modern tooling and architecture.

Engine Features

The engine includes a mesh loading and rendering pipeline with skeletal mesh rendering and animations, dynamic lighting and shadow maps, physics integration via Box3D, audio playback using miniaudio, and mesh instancing and batch rendering for performance. A post-processing pipeline, text rendering, and particle systems round out the visuals, while a scene graph with serialization and a component-based entity system handle world structure. Input handling and an in-engine editor built with ImGui complete the toolchain, and window management is handled using GLFW.

Taekwondo Global Tournament

Mobile Fighting Game · 2014 – 2016 · Hello There Games
A mobile fighting game featuring adaptive AI behavior that read player action history and adjusted its decisions. Players reported thinking they were playing another human.
▸ Click to expand
🥋 Key Art Placeholder
Contributions

Built adaptive AI in C#/Unity3D that read player action history and adjusted its decisions using a custom solution based on behavior trees. Players reported thinking they were playing another human. I also helped write netcode and matchmaking for online multiplayer using our own custom implementation.

The game was built using a deterministic game loop and input-based packets, allowing for network rollback between clients running on mobile.

The game was originally developed for mobile and then later, as a producer, I helped produce an adaptation of the game for PC called Taekwondo: Grand Prix in collaboration with the World Taekwondo Federation.
